# 可配置调研步骤系统 - 实现总结

## ✅ 已完成的后端工作

### 1. 工具注册系统
**文件**: `backend/app/research_tools/__init__.py`
- 创建了 `ResearchTool` 数据类
- 创建了 `ResearchToolRegistry` 注册表
- 支持工具的注册、查询、分类

### 2. 预置工具库
**文件**: `backend/app/research_tools/preset_tools.py`
- 已注册 11 个预置工具：
  - **数据类**: 实体识别、数据查询、数据关联
  - **分析类**: 企业分析、产品分析、市场分析
  - **信息类**: 信息源梳理、网络搜索
  - **输出类**: 报告生成、图表生成、洞察提取

### 3. API 接口
**文件**: `backend/app/main.py`
- `GET /api/research/tools` - 获取所有可用工具

### 4. 调研方案生成
**文件**: `backend/app/gemini_engine.py`
- 修改了 `generate_market_research_plan` 函数
- 返回格式改为 `mode: "plan_editable"`
- 每个步骤包含 `tool_id` 字段

## 📋 需要前端实现的功能

### 1. 步骤列表组件
- 显示所有步骤（卡片形式）
- 每个步骤显示：步骤名称、工具图标、工具名称
- 操作按钮：编辑、删除、上移、下移
- 底部有"添加步骤"按钮

### 2. 工具板组件（右侧）
- 按分类展示工具（数据类、分析类、信息类、输出类）
- 每个工具显示：图标、名称、描述
- 点击工具可添加到步骤列表

### 3. 步骤编辑弹窗
- 输入步骤名称
- 选择工具（下拉框）
- 显示工具描述
- 保存/取消按钮

---

## 🎯 使用流程

1. 用户输入问题："分析辉瑞的市场表现"
2. 后端返回可编辑的调研方案（5个步骤）
3. 前端展示步骤列表 + 右侧工具板
4. 用户可以：
   - 编辑步骤名称
   - 更换步骤使用的工具
   - 删除不需要的步骤
   - 添加新步骤
   - 调整步骤顺序
5. 用户点击"确认执行"
6. 按顺序执行各步骤

## 📊 数据格式示例

### 后端返回的方案格式
```json
{
  "mode": "plan_editable",
  "editable": true,
  "plan": [
    {
      "id": 1,
      "phase": "数据准备",
      "tool_id": "data_query",
      "action": "查询辉瑞的销售数据",
      "rationale": "获取基础数据"
    }
  ]
}
```

```json
{
  "tools": [
    {
      "tool_id": "entity_recognition",
      "tool_name": "实体识别工具",
      "category": "数据类",

      "description": "从用户问题中识别关键实体"
    }
  ],
  "categories": ["数据类", "分析类", "信息类", "输出类"]
}
```
