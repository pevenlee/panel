# Skills 中台管理系统设计方案

## 一、系统概述

Skills 中台是一个可视化的管理平台，用于：
- 📊 可视化展示所有已注册的 Skills
- ⚙️ 实时调整 Skills 配置
- 🔄 启用/禁用 Skills
- 📈 监控 Skills 执行情况
- 🧪 测试 Skills 功能
- 📝 管理 Skills 文档

---

## 二、系统架构

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    前端 (React)                          │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌─────────┐ │
│  │ Skills   │  │ 配置     │  │ 监控     │  │ 测试    │ │
│  │ 列表页   │  │ 管理页   │  │ 面板     │  │ 工具    │ │
│  └──────────┘  └──────────┘  └──────────┘  └─────────┘ │
└─────────────────────────────────────────────────────────┘
                          ↕ REST API
┌─────────────────────────────────────────────────────────┐
│                  后端 (FastAPI)                          │
│  ┌──────────────────────────────────────────────────┐   │
│  │           Skills Management API                   │   │
│  │  - GET /api/skills                               │   │
│  │  - GET /api/skills/{name}                        │   │
│  │  - PUT /api/skills/{name}/config                 │   │
│  │  - POST /api/skills/{name}/execute               │   │
│  │  - GET /api/skills/{name}/metrics                │   │
│  └──────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
                          ↕
┌─────────────────────────────────────────────────────────┐
│                Skills Registry + Storage                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐             │
│  │ Registry │  │ Config   │  │ Metrics  │             │
│  │ (内存)   │  │ (JSON)   │  │ (JSON)   │             │
│  └──────────┘  └──────────┘  └──────────┘             │
└─────────────────────────────────────────────────────────┘
```

### 2.2 技术栈

**前端**:
- React 18
- TailwindCSS (样式)
- Lucide React (图标)
- Axios (HTTP 请求)
- React Router (路由)

**后端**:
- FastAPI (API 框架)
- Pydantic (数据验证)
- JSON (配置存储)

## 四、数据模型

```json
{
  "research_plan_generator": {
    "name": "research_plan_generator",
    "description": "生成市场调研计划",
    "version": "1.0.0",
    "enabled": true,
    "config": {
      "model": "gemini-3-pro-preview",
      "max_steps": 10
    }
  }
}
```

```json
{
  "skill_name": "research_plan_generator",
  "timestamp": "2026-02-01T10:30:00",
  "success": true,
  "duration_ms": 1234,
  "error": null

```

## 五、API 设计

### 5.1 Skills 管理 API

```python
GET    /api/admin/skills              # 获取所有 Skills
GET    /api/admin/skills/{name}       # 获取单个 Skill 详情
PUT    /api/admin/skills/{name}/config # 更新配置
POST   /api/admin/skills/{name}/toggle # 启用/禁用
POST   /api/admin/skills/{name}/test   # 测试执行
GET    /api/admin/skills/{name}/metrics # 获取执行统计
```
