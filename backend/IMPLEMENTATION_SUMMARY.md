## 🎨 查询模式示例

系统已内置 4 种查询模式模板：

### 模式1: 单表时间序列
```python
drug_id = 1.0
df_sub = df_fact[df_fact['药品索引'] == drug_id].copy()
result = df_sub.groupby('年季')['销售额'].sum().reset_index()
```

### 模式2: 企业销售分析
```python
企业药品 = df_ipm[df_ipm['生产企业'].str.contains('某企业', na=False)]['药品索引'].unique()
df_sub = df_fact[df_fact['药品索引'].isin(企业药品)].copy()
result = df_sub.groupby('年季')['销售额'].sum().reset_index()
```

### 模式3: ATC分类统计
```python
药品列表 = df_ipm[df_ipm['ATC1Des'] == 'XA-消化道和代谢方面的药物']['药品索引'].unique()
df_sub = df_fact[df_fact['药品索引'].isin(药品列表)].copy()
result = df_sub.groupby('年季')['销售额'].sum().reset_index()
```

### 模式4: 多维度关联
```python
企业药品表 = df_ipm[df_ipm['生产企业'].str.contains('某药企', na=False)][['药品索引', '通用名']].copy()
merged = pd.merge(df_fact, 企业药品表, on='药品索引', how='inner')
result = merged.groupby('通用名')['销售额'].sum().reset_index()
```

## 🔧 技术细节

### 元数据生成流程
```
1. get_cached_data() → 加载并缓存数据
2. build_research_metadata(dfs_map) → 生成增强元数据
3. execute_research_step() → 使用元数据生成查询代码
4. exec(code) → 执行代码获取结果
```

### 数据预处理流程
```
1. 读取 fact.csv
2. 检测到销售额/销售量字段
3. 去除千分位逗号: "220,727" → "220727"
4. 转换为数值: "220727" → 220727.0 (float64)
5. 存入 dfs_map['fact']
```

### Prompt 工程策略
```
1. 提供完整的字段列表（禁止臆造）
2. 展示数据类型和可选值
3. 给出查询模式示例
4. 明确代码生成要求
5. 包含注意事项清单
```

## ⚠️ 注意事项

### 开发维护
1. **数据更新时**: 重新运行 `inspect_data.py` 分析结构
2. **添加新表时**: 更新 `build_research_metadata()` 函数
3. **修改字段时**: 更新查询模式示例

### 性能优化
1. **大数据量查询**: 先筛选后关联（不要先关联）
2. **缓存策略**: 重复查询可以缓存药品索引列表
3. **聚合级别**: 使用合适的时间粒度（季度 vs 天）

### 常见问题
1. **查询结果为空**: 检查企业名拼写，使用模糊匹配
2. **数值错误**: 销售额已预处理，无需手动转换
3. **关联失败**: 确认使用 '药品索引' 字段关联
