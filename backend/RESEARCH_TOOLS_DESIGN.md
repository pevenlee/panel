# 可配置调研步骤系统设计

## 一、系统概述

将固定的5步调研流程改为灵活可配置的步骤系统，用户可以：
- 增加、删除、编辑、排序步骤
- 为每个步骤选择调用的工具
- 通过右侧工具板查看和选择可用工具

---

## 二、调研工具系统

### 2.1 工具分类

#### 数据类工具
1. **实体识别工具** - 从问题中识别企业、产品、ATC分类等
2. **数据查询工具** - 构建并执行Pandas查询
3. **数据关联工具** - 关联多个数据表
4. **数据清洗工具** - 数据预处理和清洗

#### 分析类工具
5. **企业分析工具** - 生成企业分析框架
6. **产品分析工具** - 生成产品分析框架
7. **市场分析工具** - 生成市场分析框架
8. **竞争分析工具** - 生成竞争对比分析

#### 信息类工具
9. **信息源梳理工具** - 识别可能的信息来源
10. **网络搜索工具** - 模拟网络信息采集
11. **文档解析工具** - 解析外部文档

#### 输出类工具
12. **报告生成工具** - 生成HTML/PDF报告
13. **图表生成工具** - 生成可视化图表
14. **洞察提取工具** - 提取关键洞察

## 三、数据结构设计

```json
{
  "tool_id": "entity_recognition",
  "tool_name": "实体识别工具",
  "category": "数据类",
  "description": "从用户问题中识别关键实体",
  "icon": "🔍",
  "input_schema": {
    "query": "string",
    "context": "string"
  },
  "output_schema": {
    "entities": "object",
    "confidence": "number"
  },
  "config": {
    "model": "fast",
    "timeout": 30
  }
}
```

### 3.2 步骤定义
```json
{
  "step_id": "step_1",
  "step_name": "识别分析对象",
  "tool_id": "entity_recognition",
  "order": 1,
  "config": {
    "custom_prompt": "",
    "retry_on_failure": true
  },
  "dependencies": []

```

## 六、API 设计

### 6.1 获取可用工具
```
GET /api/research/tools
Response: {
  "tools": [
    {
      "tool_id": "entity_recognition",
      "tool_name": "实体识别工具",
      "category": "数据类",
      ...
    }
  ]
}
```

### 6.2 生成调研方案（返回可编辑方案）
```
POST /api/query (module=research)
Response: {
  "mode": "plan_editable",
  "plan": {
    "plan_id": "plan_123",
    "steps": [...]
  }
}
```

### 6.3 更新调研方案
```
PUT /api/research/plan/{plan_id}
Body: {
  "steps": [...]
}
```

### 6.4 执行调研方案
```
POST /api/research/plan/{plan_id}/execute
Response: {
  "results": [...]
}
```
