# 前端组件使用说明

## ✅ 已创建的组件

### 1. ToolPanel.jsx
工具板组件，显示所有可用的调研工具
- 按分类展示（数据类、分析类、信息类、输出类）
- 点击工具可添加到步骤列表

### 2. StepList.jsx
步骤列表组件，显示和管理调研步骤
- 显示所有步骤
- 支持编辑、删除、上移、下移操作
- 底部有"添加步骤"按钮

### 3. StepEditModal.jsx
步骤编辑弹窗组件
- 编辑步骤名称
- 选择工具
- 输入步骤说明

### 4. ResearchPlanEditor.jsx
主编辑器组件，整合所有功能
- 左侧：步骤列表（占 2/3 宽度）
- 右侧：工具板（占 1/3 宽度）
- 底部：取消和确认按钮
